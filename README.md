#  Mini Lottery Game (Frontend Project)
A simple and interactive Mini Lottery Game built using HTML, CSS, and JavaScript.  
The game displays 25 items with background and allows the user to randomly pick <one winning item> with a delay and sound effect.

## 📌 Features
- Displays "25 lottery items".
- One “Pick a Number” button.
- Shows “Please wait…” before selecting.
- Randomly highlights one item with green background.
- Plays a *sound effect* when a number is picked
- Clean and responsive UI

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript (DOM Manipulation)
- Audio API
